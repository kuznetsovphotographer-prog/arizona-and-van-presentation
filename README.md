# Аризона и фургон

Интерактивная презентация Александра Кузнецова: шесть исходников, 18 первых результатов нейросетей и шесть финальных фотографий с обработкой в Photoshop. После сравнений расположены 12 глав с 18 демонстрациями.

Сайт: https://kuznetsovphotographer-prog.github.io/arizona-and-van-presentation/

Репозиторий: https://github.com/kuznetsovphotographer-prog/arizona-and-van-presentation

Презентация работает как статический сайт GitHub Pages. Можно также открыть index.html локально, сохранив расположение остальных файлов.

В большом просмотре кнопки моделей и стрелки влево/вправо переключают первые генерации без закрытия окна. Колесо мыши увеличивает фотографию, перетаскивание и Shift со стрелками перемещают её. При сравнении используется общая рамка с центральным кропом, сохраняющим пропорции.

Полноразмерные JPG находятся в assets/photos/full. Для быстрого просмотра подготовлены отдельные WebP-превью. В assets/demos лежат MP4 без звука, GIF и постеры. На странице используются MP4, соответствующие GIF можно скачать рядом с каждой демонстрацией.

Иконки Lucide используются по лицензии ISC, текст лицензии находится в assets/LUCIDE-LICENSE.txt. Публикация содержит только материалы презентации. Исходные записи экрана, рабочие скрипты и резервные копии остаются локально.

Для обновления сайта отправьте новые файлы в ветку main. GitHub Pages публикует корневую папку этой ветки. Файл .nojekyll отключает обработку Jekyll.
